# هندسة المرصد المدرسي: الإصدار 0.1.0

## النطاق المعتمد

إدارة التربية والتعليم بالمديرية، بما يشمل مدارس حكومية وأهلية. الحساب الإداري الأول ينشأ فقط أثناء التهيئة الأولى. الحسابات المدرسية مقيدة بمدرسة واحدة. يستخدم إصدار MVP قاعدة محلية على جهاز واحد.

## الوحدات المكتملة

- `Core`: نماذج وصلاحيات وتحقق حسابي وتجزئة كلمة المرور.
- `Data`: قاعدة SQLite، معاملات الحفظ، أرقام مراجعة الاستمارات، سجل القرارات والأحداث.
- `Desktop`: واجهات WPF، الشاشات الأساسية، دخول المستخدمين، إدارة المدارس والموظفين، الاستمارات والتقارير.
- `Tests`: فحوص وحدات وتكامل أساسية (تحتاج تشغيلها عبر .NET SDK 10).

## دورة الاستمارة

```
draft -> submitted -> school_approved -> approved
             \               \
              -> returned <----
                    |
               new revision -> draft
```

تتطلب الإعادة للتصحيح سببا مكتوبا. في التعديل اللاحق، تنشأ مراجعة جديدة ولا يتم الكتابة فوق الاستمارة السابقة. الأعداد الرسمية مأخوذة من آخر مراجعة معتمدة فقط.

## الحقوق

| الدور | إدخال الإحصاء | مراجعة المدرسة | اعتماد المديرية | المدارس | الحسابات |
|---|---|---|---|---|---|
| Admin | الكل | لا | نعم | إدارة | إدارة |
| Statistician | الكل | لا | نعم | إدارة | لا |
| Reviewer | لا | إرجاع فقط | لا | قراءة الكل | لا |
| Principal | مدرسته | نعم | لا | مدرسته | لا |
| Entry | مدرسته | لا | لا | مدرسته | لا |
| Viewer | لا | لا | لا | قراءة الكل | لا |

فصل اعتمادي المدرسة والمديرية إلزامي: لا يستطيع مسؤول المديرية إقرار مرحلة مدير المدرسة نيابة عنه. يجب إنشاء حساب مدير مدرسة لكل مدرسة قبل اكتمال الاعتماد.

## قواعد البيانات

`users`, `schools`, `census_rounds`, `submissions`, `enrollment_rows`, `decisions`, `audit_events`, `settings`.

لا تحفظ بيانات الطلاب الاسمية في MVP. تجمع حقول كل صف `boys` و`girls`، وتحسب المجاميع في الذاكرة. تحفظ الاستمارات حسب سنة/مدرسة/مراجعة. لا يمكن حذف مدرسة لديها بيانات إحصائية؛ يتم تعطيلها.

## حاجات ما قبل الإنتاج

1. التشفير والحماية المؤسسية للبيانات المحلية.
2. قفل فترات الإدخال وجدولة الإحصاء حسب تاريخ الحصر.
3. نسخ احتياطية آمنة واختبار الاستعادة.
4. تقارير PDF وExcel XLSX وقوالب رسمية.
5. نماذج المباني والتخصصات التفصيلية والنتائج والفئات العمرية.
6. استخراج النسخ الأربع والتحقق على ويندوز، وتوقيع ملفات Installer اختياريا.
7. تطوير API ومزامنة وتدقيق مركزي حين يصبح العمل متعدد الأجهزة.
