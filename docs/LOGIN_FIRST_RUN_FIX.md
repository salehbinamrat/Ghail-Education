# تسجيل الدخول والتهيئة الأولى — إصدار 0.1.1

## التشغيل لأول مرة

1. افتح «المرصد المدرسي» من أي نسخة Windows Portable أو Installer.
2. تظهر شاشة **التهيئة الأولى** إذا كانت قاعدة البيانات المحلية خالية من الحسابات.
3. أدخل المديرية والسنة الدراسية واسم مستخدم إنجليزيا وكلمة مرور قوية مرتين.
4. اضغط **إنشاء المسؤول الأول والمتابعة**؛ الزر ثابت في أسفل الشاشة حتى عند تكبير عرض ويندوز، ويمكن تمرير الحقول.
5. ستفتح شاشة تسجيل الدخول تلقائيا، واسم المستخدم سيكون معبأ، ويجب كتابة كلمة المرور التي اخترتها.
6. بعد الدخول، يفتح البرنامج أقسام المسؤول المؤسس؛ ومن «إدارة المستخدمين» يمكن إضافة مسؤولين بصلاحيات محددة.

## زر «لدي حساب بالفعل — تسجيل الدخول»

- إذا كان حساب موجودا في قاعدة البيانات الحالية، يمكن الانتقال إلى تسجيل الدخول.
- إذا لم يُنشأ حساب بعد، يعرض البرنامج رسالة واضحة بأن إنشاء المسؤول الأول مطلوب؛ **لا توجد بيانات دخول افتراضية**.
- عند التشغيل التالي إذا كان الحساب موجودا، يتجاوز البرنامج التهيئة ويعرض تسجيل الدخول مباشرة.

## عند تسجيل الخروج

زر **تسجيل خروج** يعود إلى شاشة الدخول من دون إنهاء البرنامج؛ ويمكن استخدام حساب مسؤول آخر. إغلاق نافذة البرنامج من زر × ينهي البرنامج.

## عند ظهور «بيانات الدخول غير صحيحة»

- تحقق من اسم المستخدم المسجل وقت التهيئة (بالإنجليزية).
- تأكد من اللغة الإنجليزية وحالة Caps Lock وكلمة المرور الصحيحة. يمكن استعمال نفس اسم المستخدم بحروف كبيرة أو صغيرة.
- الحساب المعطل أو المقفل مؤقتا لا يدخل؛ بعد خمس محاولات خاطئة متتالية يقفل لمدة خمس دقائق.
- يمكن للمسؤول المؤسس إعادة تعيين كلمات مرور الحسابات المفوضة من شاشة إدارة المستخدمين.
- لم تُنفذ بعد آلية استرداد آمنة لكلمة مرور **المسؤول المؤسس** عند فقدانها؛ لا توجد طريقة تجاوز تلقائية للتهيئة.

## موقع قاعدة البيانات

تحفظ قاعدة البيانات **على الحاسوب المحلي** في:

`%LOCALAPPDATA%\SchoolObservatory\observatory.db`

نسختا Portable وInstaller تستخدمان نفس موقع البيانات عند تشغيلهما بنفس حساب Windows. عند تغيير حساب Windows أو الانتقال لحاسوب آخر، لا تنقل البيانات تلقائيا.

**تحذير:** لا تحذف ملف `observatory.db` بقصد إظهار شاشة التهيئة أو تصحيح مشكلة تسجيل الدخول؛ سيؤدي ذلك إلى فقدان بيانات المدارس والإحصاءات والحسابات الموجودة محليا.

## تغيرات شكلية

- ألوان تركوازية وزرقاء في الواجهات.
- أيقونة برنامج Windows بصيغة `assets/SchoolObservatory.ico` في ملفات التشغيل وملف التثبيت.
- شاشتا التهيئة والدخول قابلتان لتغيير الحجم ومتوافقتان مبدئيا مع تكبير الشاشة، مع تذييل أزرار ثابت.

## اختبار الجودة

تتضمن اختبارات المرحلة الحالية مراجعة:
- إنشاء المسؤول الأول ثم تسجيل الدخول بعد إعادة فتح قاعدة البيانات.
- دخول حساب مفوض وفشل كلمة المرور غير الصحيحة.
- وجود زري الإنشاء والدخول خارج منطقة التمرير في نموذج التهيئة.
- وجود زر تسجيل الدخول الفعلي في النافذة.
- بناء x86 وx64، وملفات Portable وInstaller ضمن Windows Release.

نجاح الاختبارات الآلية **ليس بديلا** عن فحص تفاعلي على Windows عند تكبير 100% و125% و150%، وعن اختبار حقيقي قبل استخدام بيانات مهمة. قاعدة SQLite الحالية غير مشفرة.
