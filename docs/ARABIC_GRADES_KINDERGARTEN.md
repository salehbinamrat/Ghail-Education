# تعريب الواجهة والصفوف والروضة وتصحيح السجلات

## أسماء الصفوف والشعب
تظهر أسماء الصفوف بالعربية في كشوف الطلاب والطباعة وملفات الطلاب والإحصاء، مع الاحتفاظ بالرمز العددي الأصلي في قاعدة البيانات لحماية السجلات القديمة.

- الأساسي: أولى أساسي إلى تاسعة أساسي (الدرجات 1 إلى 9).
- الثانوي: أولى ثانوي، ثانية ثانوي، ثالثة ثانوي (10 إلى 12).
- المجمع التربوي: الأساسي والثانوي معا.
- الروضة: روضة أولى، روضة ثانية، تمهيدي (1 إلى 3).
- لكل صف أو مستوى يمكن إنشاء شعب مستقلة مثل أ، ب، ج بحسب الحاجة وحسب العام الدراسي.

عند استيراد .xlsx أو .docx يمكن كتابة اسم الصف العربي أو رقمه. يتم رفض الصفوف غير المسموح بها لمرحلة المدرسة بالكامل قبل الحفظ.

## المحافظة على البيانات القديمة
تعتمد إضافة الروضة على عمود SQLite إضافي `is_kindergarten` بقيمة افتراضية صفر. تُبقي العملية حقل `stage` القديم والقيود الأجنبية وكل معرفات المدارس كما هي. تتم الترقية عند تشغيل الإصدار الجديد، وتُكرّر بصورة آمنة عند إعادة التشغيل دون مسح السجلات.

لا يمكن تحويل مدرسة بين الروضة والمرحلة الأساسية إذا كان لديها صفوف أو ملفات طلاب أو إحصاءات مسجلة، لمنع إعادة تفسير الرقم نفسه لمعنيين مختلفين. للمؤسسة الجديدة اختر «روضة» عند إضافتها.

## تصحيح الأخطاء
- المدرسة: اختر الصف من دليل المدارس، عدّل الحقول ثم اختر «حفظ تعديل المدرسة المحددة» بصلاحية الإدارة.
- الكادر: اختر الموظف من كشف الكادر، صحح الاسم أو الرقم أو بياناته ثم اختر «حفظ الموظف».
- الطالب: افتح ملف الطالب من كشف صفه، صحح اسمه أو رمزه أو بياناته أو شعبته ثم احفظ؛ يحافظ البرنامج على الهوية ونتائجه السابقة.
- الصف والشعبة: اختر الكشف، عدل قائمة الصف أو اسم الشعبة ثم اختر «تعديل الصف والشعبة». تظهر مطالبة تأكيد إذا كان بالكشف طلاب؛ لا ينشأ صف جديد ولا يتم حذف الطلاب.
- النتائج: اختر نتيجة مسجلة في العام الحالي لتعبئة الحقول ثم صححها واحفظ.
- التقييمات: اختر تقييم العام الحالي وعدل التقدير أو الملاحظات ثم استخدم زر التصحيح؛ يبقى المعرف الأصلي وسجل العملية.
- الحضور: اختر اليوم من الجدول لتعبئة التاريخ والحالة وتصحيحهما.

## الهوية البصرية
يستخدم البرنامج خط Arial على النوافذ والجداول وحقول الإدخال والطباعة، مع خط أبيض على الخلفيات الداكنة، وخط داكن على الحقول الفاتحة. يظهر خيار القسم الحالي في الشريط الجانبي بخلفية مختلفة وإطار مميز.

## الاختبارات والإصدار
تعمل Windows Core وWindows Release بالتوازي، وداخل Release تُشغّل اختبارات .NET قبل بناء x86/x64 Portable/Installer. لا يجري الدمج إذا فشل بناء أو اختبار أو التحقق من المخرجات الأربع.

**تنبيه أمني:** قاعدة بيانات الطلاب المحلية والنسخ الاحتياطية ليستا مشفرتين بعد. لا تعتمد بيانات حساسة حقيقية قبل استكمال التشفير واختبارات الاستعادة. كما يلزم اختبار الواجهة عمليا على أجهزة ويندوز بمستويات التكبير المختلفة.
