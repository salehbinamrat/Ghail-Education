# دليل التشغيل المختصر — المرصد المدرسي

## أول تشغيل

1. شغّل `SchoolObservatory.exe` على Windows بعد إنجاز البناء.
2. في أول تشغيل فقط، اكتب اسم المديرية والسنة الدراسية واسم حساب المسؤول وكلمة المرور الخاصة به.
3. لا توجد كلمة مرور مصنع ثابتة. احتفظ ببيانات المسؤول في وسيلة آمنة.
4. سجل الدخول بالحساب الذي أنشأته.

## تجهيز المدارس

- من «دليل المدارس»، أضف رمز المدرسة واسمها ومنطقتها وتصنيفها ومرحلتها.
- أو افتح النموذج في `samples/schools-template.csv` باستخدام Excel، ثم احفظه بصيغة CSV UTF-8 واستورده من شاشة المدارس.
- يجب أن تبقى الأعمدة بالترتيب `code,name,zone,ownership,stage`، ويقبل الحقل `ownership` القيمتين `حكومية` و`أهلية`.
- لا يعدل الاستيراد بيانات مدرسة موجودة، ويُلغى الاستيراد كله إذا حدث أي تعارض في رموز المدارس.

## حسابات المدارس

- يضيف مدير النظام مستخدما بدور `entry` (مدخل بيانات) مرتبطا بمدرسته.
- يضيف مدير النظام مستخدما بدور `principal` (مدير المدرسة) مرتبطا بالمدرسة نفسها.
- لا يستطيع المستخدم المدرسي رؤية استمارات مدرسة أخرى.

## إصدار الإحصاء

1. افتح «إحصاء الطلاب والمعلمين» واختر المدرسة.
2. أدخل الذكور والإناث لكل صف يتم تدريسه. إن كانت قيمة أحد الجنسين صفرا، اكتب 0 صراحة، ولا تتركها فارغة.
3. أكمل المعلمين والفصول والملاحظات واحفظ المسودة.
4. ارفع الاستمارة للمراجعة.
5. يدخل مدير المدرسة ويقر الاستمارة.
6. يدخل مسؤول الإحصاء أو مدير النظام لاعتمادها نهائيا.
7. إذا ظهرت مشكلة، يعيدها المراجع مع السبب. ستنشأ مراجعة جديدة عند إعادة الحفظ.

## التقارير

- شاشة «لوحة التحكم» والتقارير تعتمد **الاستمارات المعتمدة حصريا**.
- زر التصدير يخرج ملف CSV متوافقا مع Excel بترميز UTF-8، مع حماية أساسية من حقن صيغ الجداول.
- PDF الرسمي واستيراد XLSX المباشر من العناصر المتبقية بعد استلام النماذج المعتمدة.

## معلومات أمنية

هذه نسخة تطويرية فقط. التخزين المحلي لم يُفعّل تشفيره بعد، ولا تتوفر سياسة نسخ واستعادة نهائية. لا تستخدم بيانات حساسة أو تعتمد النسخة تشغيليا قبل اجتياز اختبار Windows الكامل وإكمال الحماية المطلوبة.
