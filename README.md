# المرصد المدرسي | School Observatory

نظام إحصاء مدرسي لإدارة التربية والتعليم بالمديرية، يعمل محلياً على Windows.

## حالة التنفيذ

هذه **نسخة مصدر أولية** (MVP / المرحلة الأولى)، وليست إصداراً معتمداً للإنتاج. تتضمن التهيئة الأولى وتسجيل الدخول والصلاحيات ودليل المدارس وإحصاء الطلاب والمعلمين والفصول، ومسار إرسال ومراجعة واعتماد الإحصاء، والتقارير المجمعة والتصدير إلى CSV، وسجل العمليات. تُجرى اختبارات WPF وxUnit وبناء نسخ ويندوز على GitHub Actions؛ يلزم أيضا اختبار تشغيل يدوي على أجهزة Windows قبل اعتماد الاستخدام الرسمي.

**تحذير:** قاعدة بيانات SQLite في هذه النسخة *غير مشفرة*. لا تدخل بيانات حقيقية حساسة قبل دمج تشفير SQLCipher والتحقق منه، وتدقيق الصلاحيات وإجراءات النسخ والاستعادة. يعمل التطبيق حالياً على حاسوب واحد بقاعدة محلية، وليس نظاماً متعدد الأجهزة.

## تنزيل البرنامج — أربعة ملفات مستقلة

**اختر ملفا واحدا فقط حسب نظام ويندوز وطريقة التشغيل؛ لا تحتاج تنزيل الحزم الأخرى.**

| النظام | تشغيل مباشر Portable (.zip) | تثبيت Installer (.exe) |
| --- | --- | --- |
| Windows 32 بت | [تنزيل Portable 32-bit](https://github.com/salehbinamrat/Ghail-Education/releases/latest/download/SchoolObservatory-x86-Portable.zip) | [تنزيل Installer 32-bit](https://github.com/salehbinamrat/Ghail-Education/releases/latest/download/SchoolObservatory-x86-Installer.exe) |
| Windows 64 بت | [تنزيل Portable 64-bit](https://github.com/salehbinamrat/Ghail-Education/releases/latest/download/SchoolObservatory-x64-Portable.zip) | [تنزيل Installer 64-bit](https://github.com/salehbinamrat/Ghail-Education/releases/latest/download/SchoolObservatory-x64-Installer.exe) |

- **Portable:** ملف ZIP واحد؛ فك ضغطه، ثم شغّل `SchoolObservatory.exe` مباشرة دون تثبيت.
- **Installer:** ملف EXE واحد؛ شغّله لتثبيت البرنامج، وإنشاء اختصار على سطح المكتب إذا اخترت ذلك.
- صفحة [الإصدارات الرسمية](https://github.com/salehbinamrat/Ghail-Education/releases/latest) تعرض الملفات الأربعة بشكل مستقل، مع قيم SHA-256 للتحقق من سلامة التنزيل.
- يُنشر إصدار تنزيل مباشر بعد اجتياز مساري **Windows Core** و**Windows Release** على الالتزام نفسه في `main`. في Release تنجح الاختبارات قبل بناء نسخ x86/x64.
- **مهم:** روابط التنزيل المباشر تعمل بعد اكتمال نشر أول GitHub Release بنجاح. قبل ذلك ستكون صفحة الإصدارات بلا ملفات؛ لا تستخدم تنزيل Source code بديلا عن البرنامج التنفيذي.

## المتطلبات

- Windows 10/11 حسب توافق .NET 10.
- .NET SDK 10 للتطوير.

## البناء

```powershell
dotnet restore SchoolObservatory.sln
dotnet test SchoolObservatory.sln -c Release
dotnet run --project src/SchoolObservatory.Desktop/SchoolObservatory.Desktop.csproj
```

## الوظائف المنفذة

- حساب المدير الأول: عبر شاشة تهيئة آمنة تظهر عند عدم وجود مستخدمين، بلا كلمة مرور ثابتة.
- تسجيل الدخول مع تجزئة كلمات المرور PBKDF2-SHA256 وإيقاف مؤقت بعد محاولات فاشلة.
- أدوار المدير، مسؤول الإحصاء، المراجع، مدير المدرسة، مدخل البيانات، المشاهد.
- دليل المدارس مع نطاق عمل مقيد لمستخدمي المدارس، واستيراد جماعي من ملف CSV متوافق مع Excel.
- كشوف منفصلة لكل صف وشعبة، وملف طالب مستقل يتضمن بياناته وولي أمره ونتائجه وتقييماته وحضوره.
- استيراد طلاب من جداول Excel (.xlsx) وWord (.docx)، مع التحقق من رموز الطلاب والمدرسة وعدم تنفيذ استيراد جزئي.
- تحديد جنس الطالب تلقائيا بمدارس الذكور والإناث، وإظهار الاختيار فقط في المدارس المختلطة.
- صلاحيات مستقلة لعرض سجلات الطلاب وتعديلها وإدخال النتائج والتقييمات، مع منع الدخول إلى مدرسة غير مصرح بها.
- إدخال الطلاب في الإحصاء المجمع بحسب الصف والذكور والإناث، والمعلمين والفصول، بمعزل عن سجلات الطلاب الفردية.
- حالات المسودة → رفع → إقرار مدير المدرسة → اعتماد المديرية، مع إرجاع وتصحيح بمراجعة جديدة.
- التحصيل الإحصائي من البيانات **المعتمدة** فقط.
- تصدير CSV آمن من حقن صيغ Excel.
- سجل تدقيق لتغييرات الأعمال والاعتماد.

## الخطوات التالية قبل الإنتاج

1. تشفير قاعدة SQLite والنسخ الاحتياطية SQLCipher واختبار استعادة المفاتيح.
2. المطابقة مع النماذج الإحصائية الرسمية، واستكمال الكادر والمباني والفئات العمرية والنتائج.
3. تدقيق الواجهات وإتاحة الوصول على تكبير 100% / 125% / 150%.
4. اختبارات تكامل وتشغيل على Windows x86 وx64، والتحقق من سلامة نسخ Installer وPortable.
5. قاعدة مركزية وواجهة API ومزامنة عند بدء استخدام عدة مدارس عبر الشبكة.

## مسارات CI

- `Windows Core`: تجميع واختبارات.
- `Windows Release`: تجميع واختبارات ثم بناء x86/x64 Portable وInstaller.
- الدمج في `main` يتطلب نجاح المسارين وعدم وجود إخفاقات، ويُضبط ذلك بقاعدة حماية الفرع في GitHub.
