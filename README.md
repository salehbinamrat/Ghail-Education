# المرصد المدرسي | School Observatory

نظام إحصاء مدرسي لإدارة التربية والتعليم بالمديرية، يعمل محلياً على Windows.

## حالة التنفيذ

هذه **نسخة مصدر أولية** (MVP / المرحلة الأولى)، وليست إصداراً معتمداً للإنتاج. تتضمن التهيئة الأولى وتسجيل الدخول والصلاحيات ودليل المدارس وإحصاء الطلاب والمعلمين والفصول، ومسار إرسال ومراجعة واعتماد الإحصاء، والتقارير المجمعة والتصدير إلى CSV، وسجل العمليات. لم يجر في بيئة الإنشاء بناء فعلي لـ WPF ولا تشغيل xUnit لأن .NET SDK غير متوافر؛ يجب نجاح Windows Core وWindows Release قبل النشر.

**تحذير:** قاعدة بيانات SQLite في هذه النسخة *غير مشفرة*. لا تدخل بيانات حقيقية حساسة قبل دمج تشفير SQLCipher والتحقق منه، وتدقيق الصلاحيات وإجراءات النسخ والاستعادة. يعمل التطبيق حالياً على حاسوب واحد بقاعدة محلية، وليس نظاماً متعدد الأجهزة.

## المتطلبات

- Windows 10/11 حسب توافق .NET 10.
- .NET SDK 10 للتطوير.

## البناء

```powershell
dotnet restore SchoolObservatory.sln
dotnet test SchoolObservatory.sln -c Release
dotnet run --project src/SchoolObservatory.Desktop/SchoolObservatory.Desktop.csproj
```

## الوظائف المنفذة

- حساب المدير الأول: عبر شاشة تهيئة آمنة تظهر عند عدم وجود مستخدمين، بلا كلمة مرور ثابتة.
- تسجيل الدخول مع تجزئة كلمات المرور PBKDF2-SHA256 وإيقاف مؤقت بعد محاولات فاشلة.
- أدوار المدير، مسؤول الإحصاء، المراجع، مدير المدرسة، مدخل البيانات، المشاهد.
- دليل المدارس مع نطاق عمل مقيد لمستخدمي المدارس، واستيراد جماعي من ملف CSV متوافق مع Excel.
- إدخال الطلاب بحسب الصف والذكور والإناث، والمعلمين والفصول.
- حالات المسودة → رفع → إقرار مدير المدرسة → اعتماد المديرية، مع إرجاع وتصحيح بمراجعة جديدة.
- التحصيل الإحصائي من البيانات **المعتمدة** فقط.
- تصدير CSV آمن من حقن صيغ Excel.
- سجل تدقيق لتغييرات الأعمال والاعتماد.

## الخطوات التالية قبل الإنتاج

1. تشفير قاعدة SQLite والنسخ الاحتياطية SQLCipher واختبار استعادة المفاتيح.
2. المطابقة مع النماذج الإحصائية الرسمية، واستكمال الكادر والمباني والفئات العمرية والنتائج.
3. تدقيق الواجهات وإتاحة الوصول على تكبير 100% / 125% / 150%.
4. اختبارات تكامل وتشغيل على Windows x86 وx64، والتحقق من سلامة نسخ Installer وPortable.
5. قاعدة مركزية وواجهة API ومزامنة عند بدء استخدام عدة مدارس عبر الشبكة.

## مسارات CI

- `Windows Core`: تجميع واختبارات.
- `Windows Release`: تجميع واختبارات ثم بناء x86/x64 Portable وInstaller.
- الدمج في `main` يتطلب نجاح المسارين وعدم وجود إخفاقات، ويُضبط ذلك بقاعدة حماية الفرع في GitHub.
